# Stegus Trier — International Student Arrival Hub (PWA)

Minimal, mobile-first, offline-first arrival checklist (Anmeldung, insurance, Tax-ID, Sunday/emergency pharmacy), backed by versioned city packs. EN/DE, EN-first UI, guidance only (not official advice).

## Run locally

    python3 -m http.server 8080   # or any static server

## Build/deploy
GitHub Pages via `.github/workflows/pages.yml` (Source: GitHub Pages → source "GitHub Actions").

## Content
City packs live in `content/packs/*.json`. See schema and rubric in the working brief.
